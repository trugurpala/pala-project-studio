# Pala 1.0.0

Pala is a Provider-Independent Local Software Delivery OS. It turns a
software idea into a planned, bounded, verified, and package-ready project
while keeping completion evidence and owner decisions visible.

## Install and start

Use the Codex-native marketplace flow described in [VIBE_INSTALL.md](VIBE_INSTALL.md),
then open a new Codex conversation and describe the project. The portable ZIP
is an extract-only toolkit for local installation.

## What is included

- durable ProductSpec and canonical TaskContract workflow;
- local Quality Engine evidence before DONE;
- Control Center, Failure Intelligence, and versioned policy packs;
- secret-safe, deterministic source and portable verification;
- generic GitHub publication preflight with version drift and cost guards.

## Safety guarantees

Pala does not enlarge model context or usage quotas. Hooks do not run tests,
builds, network calls, or GitHub mutations. Repository visibility, billing,
protections, release publication, and production deployment remain explicit
owner decisions. This release contains no production deployment evidence.

## Evidence

Current release identity is owned by [product-identity.json](../product-identity.json).
The final evidence manifest and release assets are attached to the GitHub
Release when publication is complete.
