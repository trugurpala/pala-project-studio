# Pala 1.1.0

Pala 1.1.0 turns the local delivery engine into a professional, capability-
oriented Workbench while keeping the normal user experience simple.

## Highlights

- Capability-first code understanding, security, and browser verification.
- One read-only PALA CONTROL CENTER with explicit-open-only behavior.
- Capability-oriented Doctor with version, ownership, integrity, provenance,
  freshness, offline, daemon, global-mutation, and remnant checks.
- Transactional installation and update with verified staging, atomic
  activation, rollback, foreign-asset preservation, and truthful offline state.
- Quality Engine acceptance mapping, Failure Intelligence, and ReleaseTruth
  remain the product authorities for completion, known fixes, and publication.
- Deterministic Windows x64 portable package plus clean install and upgrade
  verification from published 0.4.4 and 1.0.0 releases.

## Capability policy

Normal users work with capabilities, not provider internals. Exact provider
versions and integrity details are available in [Architecture](ARCHITECTURE.md).
Providers remain advisory and cannot mark a task complete.

## Privacy and safety

Telemetry, shared daemons, silent project mutation, automatic helper UI,
credential logging, and global PATH mutation are disabled. Commit, push, tag,
release, and deploy remain separately authorized actions.

The authoritative portable asset is `pala-project-studio-1.1.0.zip`. Its final
checksum and concise evidence manifest are published beside the GitHub Release.
