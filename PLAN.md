# Pala roadmap

Pala 1.1.0 is feature-complete. The current roadmap is intentionally short:

1. Keep the public repository product-first and free of development diary
   material.
2. Maintain the capability registry, local-first privacy boundary, Quality
   Engine, Failure Intelligence, ReleaseTruth, and Control Center contracts.
3. Require full local release verification plus green remote CI before any
   public release.
4. Run the separate clean-user installation canary only after public release.

Historical milestone plans remain available in Git history and are not current
product authority. Canonical active work lives in TaskContract/WorkflowStore;
this file is a concise roadmap projection.
