# Pala roadmap

Pala 1.1.1 is a bounded patch milestone. The current roadmap is intentionally short:

1. `M74-T1`: bootstrap the canonical Control Center without an active project,
   preserve it for active/corrupt project state, and remove current hard-coded
   release identity.
2. Prove installed Pala workflow and Quality authority in a disposable Codex
   candidate project with a controlled failure and repair.
3. Require full local release verification plus green remote CI before `v1.1.1`.
4. Run a new clean public installation and installed-plugin self-test after publication.

Historical milestone plans remain available in Git history and are not current
product authority. Canonical active work lives in TaskContract/WorkflowStore;
this file is a concise roadmap projection.
