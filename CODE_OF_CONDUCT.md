# Code of Conduct

## Our pledge

We want Pala contributors and users to feel safe reporting bugs, proposing
changes, and disagreeing about design—without harassment or bad-faith pressure.

## Expected behavior

- Be direct and kind.
- Focus critique on code, docs, and decisions—not people.
- Assume good intent; ask clarifying questions before escalating.
- Respect security boundaries: no public dump of secrets, private project data,
  or weaponized repros.

## Unacceptable behavior

- Harassment, hate speech, or personal attacks
- Publishing others’ private information
- Deliberately sabotaging CI, installs, or other contributors’ work
- Pressuring maintainers to merge unsafe hook/network/telemetry changes

## Enforcement

Report concerns privately to the repository owner (same channel as
`SECURITY.md`). Maintainers may warn, edit, reject, or ban as needed to keep
the project usable.

## Scope

This Code applies in GitHub spaces for this repository (issues, PRs,
discussions) and when someone is representing the project in those spaces.

Inspired by the spirit of the Contributor Covenant, kept short on purpose.
