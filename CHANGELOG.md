## [1.0.0] - 2026-08-12

Pala 1.0 is the first stable public release of the Provider-Independent Local
Software Delivery OS.

### Added

- ProductSpec, canonical TaskContract execution, WorkflowStore leases, and
  evidence-gated Quality Engine completion.
- Local Control Center, Failure Intelligence, versioned policy packs, and
  reproducible source/portable/installed verification.
- Generic publication governance for hygiene, secret scanning, version
  consistency, cost safety, documentation, and mandatory remote read-back.
- English-first public documentation and a practical Turkish README.

### Changed

- Release identity is promoted to `1.0.0`; historical 0.x records are retained
  as historical records and are not current-release evidence.

### Security and reliability

- Hooks never run tests, builds, network calls, or remote mutations.
- Publication stops on unknown visibility, permissions, paid paths, secret
  leaks, or required version drift.
- Real production deployment is not part of this GitHub release evidence.
