# Demo Software Project

Sample inventory app used only to demonstrate Pala's memory contract, Status
panel, and SQLite catalog seed. Technology tags are discovery hints, not stack
approval.

## Outcome

A tiny CLI that lists demo SKUs from a local JSON file, with a status surface
and truthful verification labels.

## Non-goals

- Production customers or real inventory data
- Cloud deploy, billing, or telemetry
- ChatGPT Plus install claims
